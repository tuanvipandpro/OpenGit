# Kế hoạch thực thi 0.1.0

Ngày lập: 2026-10-24. **Planned — chưa implementation, chưa release.** `VERSION` vẫn `0.1.0`; tài liệu này không tạo scaffold hay nâng version. Đọc [roadmap R1/R6](../roadmap.md), [kiến trúc](../architecture.md), [kế hoạch tổng thể và acceptance IDs](implementation-plan.md), [workflow](../development-workflow.md) trước dispatch. Mọi đường dẫn code bên dưới là **đề xuất tương lai**, không phải file đã tồn tại.

## Mục tiêu và readiness

Must: workspace nhiều repo, open/recents/status/branch/identity, phát hiện operation ngoài app; task state/error panel; clone HTTPS/SSH public/private và local, GUI auth, progress/cancel an toàn, destination không bị ghi đè và restart reconciliation. Chưa gồm graph/Hide/Solo/diff, daily mutations, resolver, cross-repo cherry-pick hay quản lý đầy đủ worktree. Bare repo chỉ metadata read-only; linked worktree được discovery/grouping; nested repo chỉ mở khi chọn rõ.

Evidence read-only đã thu thập ngày 2026-10-24 tại [task 003](../tasks/003-application-planning.md): Git `2.56.0.windows.2`, Node `24.19.0`, GCM `2.9.1`, Windows OpenSSH `9.5p2`; registry WebView2 `155.0.4283.62`. pnpm fallback được tìm thấy nhưng version/chạy dự án chưa kiểm tra. `cargo`, `rustc`, `rustup`, `cl`, `npm` không có trong PATH; đường dẫn Rustup/vswhere thường dùng không có: **chưa xác nhận cài đặt**, không kết luận tool không tồn tại. Sự hiện diện của runtime không chứng minh build/GUI auth hoạt động.

Đối chiếu readiness theo [Tauri prerequisites](https://v2.tauri.app/start/prerequisites/) và [Vite guide](https://vite.dev/guide/), không tự đặt exact dependency pins trước thử tương thích. Private HTTPS/SSH live fixture chưa được cung cấp; gate này **BLOCKED đến khi có truy cập được cấp phép**. Repo bare local/fake helper không chứng minh SSO/private remote thật. Blocker live auth không chặn planning/readiness/scaffold đủ điều kiện; không cần yêu cầu secret hay đưa credentials vào tài liệu.

## Validation dự kiến, chưa phải lệnh đã tồn tại

Hiện chưa có manifests/scripts nên **không chạy hoặc tuyên bố pass** các lệnh sau. 02 phải tạo, xác minh và ghi lệnh thật vào README trước khi dùng. Bộ lệnh đề xuất cho các packet là:

```text
pnpm typecheck
pnpm test
pnpm build
pnpm tauri build
cargo fmt --manifest-path src-tauri/Cargo.toml --check
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings
cargo test --manifest-path src-tauri/Cargo.toml
```

Gọi bộ này là V-BASE trong packet: chạy subset liên quan đã hiện thực và kiểm tra tích hợp khi gate yêu cầu; ghi exact commands, fixture, exit/result, không ghi trước kết quả. `cargo test --manifest-path src-tauri/Cargo.toml --test <test_name>` là mẫu lệnh **tương lai** cho integration test có tên trong packet, chỉ hợp lệ sau khi target thật tồn tại. 02 chọn driver/lệnh desktop E2E dựa trên thử Tauri/Windows thực tế; không giả định Playwright web là desktop E2E. Manual evidence hợp lệ phải nêu phiên bản, thao tác và quan sát; không gọi là automated pass.

**Own:** `docs/testing/0.1.0-release-gate.md`, `README.md` (hướng dẫn người dùng/lệnh đã xác minh, chuyển quyền ghi nối tiếp owner 02). Không sở hữu code; findings chuyển lại module owner qua orchestrator.

1. Tổng hợp evidence toolchain/version, build/launch/reproducibility và A1/A6/F1–F4; kiểm tra required failures/live coverage chưa đóng.
2. Chạy validation tích hợp và kiểm tra hướng dẫn người dùng theo commands thật; nêu giới hạn provider/environment/unsupported cases.
3. Chuẩn bị snapshot và packet review độc lập; sửa docs trong scope, chuyển code findings về owner và giữ finding IDs cho re-review.
4. Giao `READY_FOR_REVIEW` khi đủ evidence, hoặc BLOCKED với thiếu hụt rõ; không tự approve, release/tag/commit/push.

**Validation:** V-BASE tích hợp, Windows launch, repeatable install/build từ lockfiles, version sync và review coverage. **Done:** handoff review đầy đủ; version chỉ được coi đạt gate khi reviewer PASS, không required finding hoặc blocked check; phát hành cần ủy quyền riêng.

## Ma trận lỗi và bằng chứng bắt buộc

Mọi Git mutation/fault injection chạy trong disposable repositories. Test helper không dùng production URL/credential; cleanup có ownership guard. Mỗi ô phải có evidence target/fixture/result trong 12, không coi thiết kế là test đã chạy.

| Tình huống | Quan sát bắt buộc | Owner / kiểm tra |
| --- | --- | --- |
| Missing Git/toolchain, unsupported version | Readiness lỗi actionable, không spawn lệnh không có hoặc tuyên bố build pass | 01–03; environment + process boundary |
| Malformed/NUL output, unknown headers, Unicode/raw paths, OID format | Parser an toàn, giữ identity; unknown header bỏ qua, record lỗi có fallback | 03/05/08; inspection fixtures |
| Injection/ref/path/scope, Windows drive vs SCP/custom helper | Reject trước spawn; argv literal, handle gắn scope, URL secret bị từ chối | 03/09/10; boundary tests |
| Destination tồn tại/TOCTOU/junction/actor ngoài app | No-replace atomic publish; sentinel nguyên vẹn, không xóa đích người dùng | 04/10/12; race fixtures |
| Disk full/permission/rename/network/checkout fail | Failure có cấu trúc, journal hợp lệ; staging cleanup có scope, nguồn/đích an toàn | 08/10/12; injected failures |
| Cancel queued/auth/network/checkout/prepublish | Terminal đúng một lần; owned Git tree dừng, shared agent/browser vẫn sống | 03/06/09/10; lifecycle + GUI |
| Cancel đồng thời publish hoặc ngay sau thành công | Thắng trước publish hoặc Success sau publish; không xóa published target | 06/10/12; deterministic race |
| Crash trước/sau publish, trước registry commit | Reconcile idempotent, không overwrite/auto-resume mù, registry không duplicate | 06/10/12; restart fixtures |
| External Git/linked worktrees dùng common directory | Lock nội bộ đúng scope/thứ tự, recheck preconditions vì CLI không bị khóa | 04–06/12; contention/external-state |
| SQLite corrupt/migration/permission fail | Transaction rollback và giữ database gốc; không lấy cache làm Git truth | 04/06/12; reopen/migration fixtures |
| Stale/reordered/missing events, đổi repo | Generation chặn read cũ; sequence + snapshot resync, không double terminal | 05–07/11/12; component + lifecycle |
| Denied/expired/SSO/browser cancel/proxy/CA/host mismatch | Safe actionable error, không weaken TLS/SSH; live/private ô chưa có quyền là BLOCKED | 09/12; authorized GUI matrix |
| Unknown error hoặc secret-bearing stderr/URL/prompt | Fallback an toàn; bounded redaction trước UI/log/SQLite; canary không xuất hiện | 03/09–12; scan artifacts |

## Batching, review và completion

Theo [chiến lược tổng thể](implementation-plan.md), dự kiến 7–9 handoff, ba review gates: 01–08 local demo/foundation; 09–10 auth/clone core; 11–13 integrated. Reuse worker/reviewer cho repair; max hai subagent theo policy, thường một. 07 và 08 chỉ song song sau 06 với ownership riêng và lợi ích thời gian được ghi. Owner 02 tích hợp shared entrypoints sau mỗi nhánh trước validation.

Trước/sau batch, orchestrator kiểm dependency, scope, evidence hiện có, handoffs/usage, findings và năng lực model. Usage hiện **chưa biết**, không có budget mặc định hoặc cost estimate được đo. Sau hai lần thất bại cùng cách giải quyết, dừng và replan; worker chỉ yêu cầu escalation có evidence. Review độc lập phải kiểm tra mọi acceptance và delta sửa theo ID; worker không tự đóng finding.

Kế hoạch này hoàn tất về mặt tài liệu không đồng nghĩa application/release hoàn tất. Hiện không có app tests/build được chạy. Implementation chỉ hoàn tất khi checks thật và reviewer PASS; required live gate bị chặn thì 0.1.0 chưa hoàn tất. Không phát hành/tag hoặc tăng `VERSION` từ tài liệu này.
