## Frozen design decisions to materialize in S1

- Keep foundation IPC v1 additive. New commands: open_history, load_history_page, search_history, get_commit_details, get_commit_diff, get_repository_view, save_repository_view and active watcher subscription/deactivation. Reads echo repo/worktree/generation and snapshot ID.
- Opaque backend-issued window/scope/snapshot/query-bound cursors and commit/file handles; renderer supplies no offsets, filesystem paths, revision expressions or argv.
- Immutable resolved positive root OIDs per history session, topo-order traversal and raw parent truth. Fingerprint refs/HEAD/shallow and identity around queries; invalidated sessions return ExternalChange. Mark off-page/shallow/missing parents explicitly. Replace/graft/promisor behavior must be proven or explicitly unsupported, never silently incorrect or automatically fetched.
- Hide removes ref roots/decorations; Solo is union ancestry of selected roots. Never subtract hidden ancestry with negative roots. Detached HEAD is a default root; stash remains explicitly inspectable, not default stash internals in graph.
- Search all reachable history independent of visible filters/pages; literal bounded query, SHA prefix/message/full author, ref name search. Outside-filter results open details with explicit status without silently altering saved filters.
- Diff uses backend-resolved blob OIDs, raw path identity and file handles; no renderer path. Root/merge-parent modes explicit; no external diff/textconv. Typed binary/gitlink/large/encoding limits, no silent truncation. Lazy readonly local Monaco workers, no CDN/wildcard/unsafe-eval CSP.
- Transactional schema3 view preferences per repo: qualified ref names/filter, selected OID, anchor+offset, layout/diff/sidebar state and view revision. Never persist runtime cursors/handles; delayed saves cannot overwrite newer state. Linked worktrees share repo preferences but sessions remain worktree-bound.
- Single refresh coordinator, one active request + one pending rerun, visible-active fallback30s, focus debounce/postoperation, hidden dirty/resume once. Quiet background content; manual or slow after~500ms feedback.
- Proposed exact dependencies: TanStack React Virtual3.14.22, Monaco0.57.0, notify8.2.0. Compile/lock verification required. Proposed bounds: default page200/max500, search page<=100/query512bytes; bounded sessions/handles TTL and diff buffers within8MiB runner output/JSON budgets. S1 records exact constants.

## Validation / failure gates

- DAG oracle across page sizes1/2/200, merge/octopus/equal and backdated timestamps, unrelated roots; no invented/dropped parents across filter/page boundaries.
- Unborn/bare/detached/shallow/annotated and noncommit tags, missing/pruned/partial objects, replace/graft semantics. No automatic network or mutation from reads.
- Window/scope/cursor replay/TTL/caps, malformed/option-looking/oversized input, cancellation/timeouts/selection races. Repo refs/index/sentinels unchanged.
- Diff add/delete/root/rename/merge parent, unusual paths/symlink/gitlink/binary/encoding/large files; configured external diff/textconv canary never executed.
- View upgrades0/1/2→3, preserved workspace/clone intents, rollback/readonly/corrupt DB, stale saves and per-repo/linked selection.
- Refresh hidden/focus/manual/operation overlap, quiet/slow feedback, one rerun maximum; watch burst/atomic rewrite/overflow/drop/failure/close/forget/linked common directory.
- Monaco worker failure/resources, local lazy chunk, rapid file switch; actual desktop two viewport sizes/Canvas graph/search/filter/reopen, measured baseline without invented thresholds.

Existing commands: pnpm check:version/typecheck/test/build; dot-source scripts/dev-env.ps1 then cargo test --manifest-path src-tauri/Cargo.toml --no-default-features --locked --offline, core clippy all-targets -Dwarnings and fmt --check. New dependencies require verified fetch/lock before offline checks. Native tauri-driver Python harness exists; new script names/commands only become evidence after authored/run. Final build must use Tauri CLI without e2e feature.
