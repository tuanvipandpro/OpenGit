## Contract

Display `ChangeDiff.content` stays opaque, never patch authority. Add structured
hunks/rows: hunkId, lineId|null, kind(context/add/delete), oldLine/newLine|null,
text and hasLf. Closed partialEligibility: eligible/binary/encoding/lineEndings/
attributes/rename/mode/tooLarge/complexityLimit/filePresenceOnly/unsupported.

`resolve_change_selection({scope,changeHandle,diffId,selection:{kind:hunks,hunkIds}
|{kind:lines,lineIds}})` returns echoed scope/changeHandle/diffId +selectionHandle.
Use existing stageSelection/unstageSelection intents. No renderer patch/path/OID.

diffId hashes source changeHandle, authoritative endpoint blob digests/existence/
mode, snapshot stamps and algorithm version; it is not standalone authority.
Resolver validates original source grant/scope, reconstructs strict data and IDs.
Selection identity uses closed encoding with side/raw path/source binding/digest
and at most64 canonical ordinal ranges (u32 pairs); identity<=2048B, grant<=4KiB,
request<=16KiB, expiry never beyond source grant. Reject empty/duplicate/foreign/
overlap/excess fragmentation wholesale. One file/side per grant; duplicate-file
grants in one mutation are rejected. No patch/blob cache or registry.

## Exact candidate

Stage endpoints L=index,R=working snapshot. Unstage L=HEAD,R=index (unborn absent).
Read strict authoritative bytes independently from the display diff. Preserve LF
in each line token; never normalize. Deterministic bounded LCS after common
prefix/suffix trim, deletion-first tie break; max1,048,576 cells/4MiB scratch,
otherwise complexityLimit whole-file fallback.

Equal emits token. For Stage, selected delete is omitted and selected add emitted;
unselected delete retained, unselected add omitted. For Unstage, selected delete
is emitted and selected add omitted; unselected delete omitted/add retained.
Hunks expand to edit-unit IDs. Repeated equal lines use occurrence ordinals.
Reject a selection placing an unterminated token before another token; never add
LF silently. New/deleted partial files work when edit units exist; endpoint becomes
absent only when all changes to absence selected. Empty-but-present is distinct;
presence-only changes use whole-file fallback.

Eligibility: regular UTF-8 text in existing limits, stable mode and proven byte
roundtrip. Binary/NUL, CRLF/bare CR, encoding/conversion/filter/textconv/diff-driver,
rename/copy/type/mode/gitlink/unmerged unsupported for partial. Verify effective
attributes; core.autocrlf alone is not enough to assume conversion. Clear fallback.

Within A before-write transaction only, hash candidate blob without filters and
update alternate index with backend mode/raw path/OID; verify exact selected entry
and untouched entries, then reuse A tree/lock/publication/quiescence/recovery.

## Amend

Real-index Git commit --amend --file=- only for explicit amend=true, defaultfalse.
Require HEAD; allow message-only without staged changes. Expected parents are
old commit's parents in order, not old HEAD itself. Root has zero parents; preserve
merge order, author/hook/signer behavior. Verified no-op can retain same OID.
No reset-author/bypass/reset/retry. UI commit form opens with HEAD even when0staged,
toggle/message stales preview, toggle/draft memory-only and selection-owned.
