octopus merge, shared ancestry, an unmerged branch outside Solo(main), unrelated
root, annotated tag, symbolic remote HEAD, Unicode rename/delete/binary/symlink

backs the graph fixture; raw shallow commit parents will be checked using

## Harness and limits

- Native scripts use actual Tauri/WebView2 and owned Git repos; only folder
  selection is injected by the e2e feature. Desktop/production version asserts
  now read VERSION.
- Refresh instrumentation initially could not observe bridge/forwarder command
  counts; those approaches were stopped and removed. The passing native test
  observes real rendered inspection timestamps and native visibility, combined
  with unit/source request-count proof. No fake backend response is used.
- Windows environment keys are normalized case-insensitively before applying
  explicit removal. Harness negative controls4 PASS, including early-restart
  HTTP requests and differently-cased overrides/unsets.
- Fixture cleanup first encountered readonly Git objects; a guarded retry now
  changes only files inside the verified unique fixture root. Complete fixture
  creation/linked/shallow/read-preservation/cleanup passed afterward.
- History safe-read capability and final limits are described in
  [history contract](../architecture/history.md); unsupported partial/promisor,
  replace/graft histories are rejected explicitly, not read with altered
  ancestry or automatic fetch.

Use the exact e2e build artifact under test, Python3.11+, tauri-driver and a
WebView2-compatible EdgeDriver as configured in `tests/e2e/desktop_smoke.py`.
Run from the workspace on the normal Windows desktop token. Each history
script creates and removes its own disposable repositories below `.tmp`.

$env:OPENGIT_E2E_EXECUTABLE = 'C:\absolute\path\to\e2e\opengit.exe'

acceptance additionally requires `src-tauri/target/release/opengit.exe` built
without e2e; the environment variable names the separate seed artifact. Existing

Known product boundaries: Windows is the verified platform; history sessions are
bounded100000 commits and unsupported promisor/replace/graft semantics fail
explicitly. Native watcher loss degrades to periodic refresh. Windows may prevent
moving an unwatched ancestor of a watched Git directory; close the app before such
storage moves. Linked worktrees share per-repo preferences. Automatic background
clone activation followed by immediate app close guarantees only previously
acknowledged preferences for the old repo. External GCM/OAuth/SSO compatibility,
installer/signing and broader release certification remain outside this version's
owned acceptance. See the history contract for resource/diff/path limits.
